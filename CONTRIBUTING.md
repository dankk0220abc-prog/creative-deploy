# Contributing to CreativeDeploy

Develop from a feature branch and merge changes into `main` through a pull request.
Do not push directly to `main`.

- Run the focused tests and checks that match the changed scope.
- The GitHub Actions `candidate` check must pass before merging.
- Report secrets and security vulnerabilities through the private process in
  [SECURITY.md](SECURITY.md); do not open a public Issue containing sensitive data.
- Do not commit real credentials, real customer assets, or private environment
  files.
- AI, OCR, Agent workflows, and RAG are outside the currently authorized scope.
- Contributions are made under the repository's [Apache-2.0 license](LICENSE).
